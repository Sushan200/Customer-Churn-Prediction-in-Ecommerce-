# Customer Churn Prediction in E-commerce Business Using Machine Learning Models
This report is structured as follows:
i.	Introduction: Provides an overview of the problem statement, the role of analytics, and a brief literature review.
ii.	Data and Exploratory Data Analysis (EDA): Describes the dataset used for analysis and conducts preliminary exploratory data analysis.
iii.	Data Pre-processing: Discusses the pre-processing steps undertaken to prepare the data for machine learning analysis.
iv.	Machine Learning Analysis: Presents the methodology and results of the machine learning analysis, including the CNN model and logistic regression model.
v.	Discussion and Conclusions: Summarizes the technical findings, discusses implications for E-commerce businesses, and outlines future research directions.
This structured approach enables a comprehensive examination of the customer churn prediction problem within the E-commerce sector, facilitating informed decision-making and strategic planning for businesses operating in this domain
